# Senior Friendly Kiosk UI

중장년·노년층 사용자를 위한 패스트푸드 키오스크 UI 개선 프로젝트

## 프로젝트 소개

이 프로젝트는 키오스크 사용이 익숙하지 않은 중장년·노년층 사용자를 위해 패스트푸드 매장의 키오스크 UI를 개선한 것입니다. UX/UI 수업에서 기획한 내용을 Claude Code를 활용해 실제 웹 프로젝트로 구현했으며, 큰 글씨, 큰 버튼, 명확한 선택 상태 표시 등을 통해 사용 난이도를 낮추었습니다.

## 주요 기능

- **시작 화면**: 로고 및 태그라인 표시
- **글씨 크기 선택**: 일반 모드(기본) 또는 중장년·노년층 큰 글씨 모드(1.4배 확대)
- **이음 방법 선택**: 매장 식사 또는 포장
- **메뉴 선택**: 카테고리별 메뉴 (추천, 세트, 버거, 사이드, 음료)
- **세트 옵션 선택**: 음료(콜라, 사이다, 제로콜라)와 사이드(감자튀김, 치즈스틱) 선택
- **장바구니 관리**: 메뉴 추가, 수정, 제거
- **주문 확인**: 선택한 모든 메뉴와 금액 확인
- **주문 완료**: 자동 생성된 주문번호 표시

## 화면 흐름

```
시작 화면 → 글씨 크기 선택 → 이음 방법 선택 → 메뉴 선택
↓
[1개 선택: 자동 이동] / [2개+ 선택: 결제 버튼]
↓
세트 옵션 선택 → 장바구니 추가
↓
(여러 메뉴 선택 시 반복)
↓
장바구니 확인 (수정/제거 가능) → 결제하기
↓
주문 완료 → 처음으로 돌아가기
```

## 사용 기술

- **React** 18.3.1 - UI 프레임워크
- **TypeScript** 5.3.3 - 타입 안전성
- **Vite** 5.0.8 - 번들러 및 개발 서버
- **CSS** - 스타일링

## 실행 방법

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속합니다.

### 빌드
```bash
npm run build
```

빌드 결과는 `dist` 폴더에 생성됩니다.

## 프로젝트 구조

```
src/
├─ App.tsx                  # 메인 앱 컴포넌트, 화면 라우팅
├─ main.tsx                 # 엔트리 포인트
├─ index.css                # 전역 스타일
├─ components/              # 재사용 가능한 컴포넌트
│  ├─ Header.tsx           # 상단 헤더 (도움말 버튼)
│  ├─ Button.tsx           # 통일된 버튼 컴포넌트
│  └─ Toast.tsx            # 알림 토스트
├─ context/
│  └─ OrderContext.tsx     # Context API 기반 주문 상태 관리
├─ pages/                  # 화면별 페이지 컴포넌트
│  ├─ StartScreen.tsx      # 시작 화면
│  ├─ OrderTypeSelect.tsx  # 이음 방법 선택
│  ├─ MenuScreen.tsx       # 메뉴 선택
│  ├─ OptionsScreen.tsx    # 세트 옵션 선택
│  ├─ CartReviewScreen.tsx # 장바구니 확인
│  ├─ OrderConfirmScreen.tsx # 주문 확인 (사용하지 않음)
│  └─ OrderCompleteScreen.tsx # 주문 완료
└─ data/
   └─ menuData.ts          # 메뉴 데이터 정의
```

## UI 설계

Figma를 이용해 1080×1920 기준의 세로형 키오스크 화면을 설계했습니다. `figma-ui-reference` 폴더의 설계 이미지를 참고해 React UI를 구현했으며, 다음 특징을 적용했습니다:

### 화면 비율 및 반응형
- 1080×1920 (9:16 세로형) 기준 설계
- 브라우저 크기에 맞춰 동적으로 화면 스케일 조정
- 내부 요소는 고정 크기 유지, 전체 화면 축소

### 큰 글씨 모드
- 기본: 일반 글씨 크기
- 큰 글씨: 1.4배 확대
- CSS 변수 `--text-scale` 사용으로 동적 적용

### 시각적 개선
- 큰 버튼 (최소 높이 70px)
- 넉넉한 여백 (20-60px)
- 선택 상태 표시 (체크마크 + 테두리 + 텍스트)
- 높은 색상 대비 (검정 텍스트, 흰색 배경)

## 구현하지 않은 기능

이 프로젝트는 UI 프로토타입이므로 다음 기능은 구현되지 않았습니다:

- 실제 카드 결제 시스템
- 회원가입 / 로그인
- 포인트 적립, 쿠폰 등 마케팅 기능
- 실제 POS 시스템 연동
- 재고 관리 시스템
- 데이터베이스 연동
- 음성 안내
- 영수증 출력

## 개발 배경

기존 키오스크에서 발견한 문제점:
- 작은 글씨와 버튼으로 읽고 조작하기 어려움
- 메뉴 위치를 찾기 어려움
- 선택 상태를 확인하기 어려움
- 여러 화면을 이동하면서 이전 선택을 다시 확인해야 하는 경우 발생
- 뒤의 사람이 기다린다는 부담감으로 급하게 주문하게 되는 문제

이 프로젝트는 이러한 문제들을 해결하기 위해 설계되었습니다.
