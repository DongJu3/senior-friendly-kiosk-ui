## 구현 원칙
- 첨부 이미지의 화면 구조, 배치, 글자 크기, 간격, 버튼 크기, 색상 분위기를 우선 참고합니다.
- 중장년·노년층 대상이므로 큰 글자와 큰 터치 영역을 유지합니다.
- 선택 상태는 색상만이 아니라 체크/테두리/텍스트로도 구분합니다.
- 실제 결제, 로그인, 포인트, POS 연동은 구현 범위에서 제외합니다.
- 기존 기능이 있다면 기능은 유지하면서 UI를 이미지에 맞춰 수정합니다.
